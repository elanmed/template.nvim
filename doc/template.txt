`TEMPLATE.NVIM`                                       *template-template.nvim*


A minimal Neovim plugin template with an empty setup entry point.


------------------------------------------------------------------------------
FEATURES                                                   *template-features*


- 1 source file (5 LOC), 1 test file (20 LOC), no runtime dependencies
- No plugin behavior yet: `setup()` is a placeholder for implementation
- A minimal `mini.test` test scaffold and Make targets for testing, linting,
  formatting, and generating help documentation

------------------------------------------------------------------------------
EXAMPLE CONFIG                                       *template-example-config*


The plugin loader calls `setup()` automatically when the plugin is loaded. The
setup function is an empty scaffold:

>lua
    require("template").setup()
<

------------------------------------------------------------------------------
PLUG REMAPS                                             *template-plug-remaps*


This template defines no `<Plug>` mappings.

`REQUIRE("TEMPLATE").SETUP()`           *template-require("template").setup()*
